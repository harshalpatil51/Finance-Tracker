# 🚀 Finance Tracker (Personal Financial Dashboard)

A modern, privacy-first personal finance application to track **Income**, **Expenses**, and **Savings / Investments** with interactive monthly trends and category breakdowns.

---

## 🌟 Key Features

* **All-in-One Cash Flow Tracking**: Log Inflows (Salary, Business), Outflows (Groceries, Bills), and Savings (Mutual Funds, EPF, Deposits) in one unified dashboard.
* **Monthly Financial Trends**: Visual line charts tracking Income vs. Expenses vs. Savings month-over-month.
* **Category Breakdown Analytics**: Interactive donut charts to visualize expense and investment allocations.
* **Monthly Category Budgeting**: Set monthly spending limits per category with dynamic warning thresholds and progress bars.
* **Multi-Category & Custom Tags**: Support for built-in and user-defined custom categories on the fly.
* **Data Backup & Export**: Export financial records directly to **CSV** (spreadsheet) or **JSON** backup files.
* **Mobile & PWA Ready**: Fully responsive layout designed to be added to your mobile home screen as a web app.
